# MoneyFamily
Cross-platform personal and family finance manager.
Platforms:
- Windows
- macOS
- iPhone
- iPad
Core Features:
- Multi-user family management
- Accounts and budgets
- Bank reconciliation
- Money by Jumsoft CSV import
- Bank CSV import
- Reports and analytics
- Cloud synchronization
Future Features:
- AI transaction categorization
- Open Banking integration
- OCR receipt scanning
